# Electronic Tasbeeh Counter

A simple web application for counting Tasbeeh (Dhikr) built using HTML, CSS, and JavaScript.

## Features
- Interactive Tasbeeh counter
- Clean and responsive user interface
- Easy-to-use design
- Reset and counting functionality
- Beautiful Islamic-themed background

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to practice front-end web development skills while building a useful Islamic tool for daily remembrance (Dhikr).
